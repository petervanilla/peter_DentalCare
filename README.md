## 1. 실행 방법

### 방법 A — 목서버 (가장 권장 · S7) — 3역할 실시간 동기화

```bash
cd mirimiso-webapp
node server/server.js          # PORT 환경변수로 변경 가능 (기본 8080)
# → http://localhost:8080  (웹앱 서빙 + 케이스 API + 감사로그)
```

- **멀티탭 실동기화 데모**: 브라우저 탭 2개를 열어 한 탭은 *의료진*, 한 탭은 *기공소*로 진입 →
  병원이 주문 제출하면 기공소 큐에 ~2초 내 도착, 기공소의 수정 요청은 병원에 긴급 배지로 즉시 반영.
- **권한 분리 서버 강제**: 기공소(role=lab) API 응답에서 환자 소견·AI 임상 제안·상담 히스토리를
  서버가 제거(`_masked` 고지) — 클라이언트를 수정해도 우회 불가. 열람은 감사로그 기록.
- API 요약: `GET/POST /api/cases` · `PATCH /api/cases/:id` · `POST /api/cases/:id/order` ·
  `POST /api/cases/:id/lab-actions` · `GET /api/events` · `GET /api/audit` · `POST /api/reset`
- 단일 파일도 같은 서버에서 제공: `http://localhost:8080/bundle`

### 방법 A-2 — 인증 모드 (M1 실서비스 미리보기)

```bash
cd mirimiso-webapp && npm install            # better-sqlite3 (인증·영속 모드에만 필요)
MM_AUTH=1 node server/server.js              # 초대코드 로그인 게이트
MM_AUTH=1 MM_DB=data/pilot.db node server/server.js  # + SQLite 영속 (재시작 후 데이터·세션 유지)
# 데모 초대코드: 의료진 MIRI-CLINIC-2026 · 기공소 MIRI-LAB-2026 · 환자 MIRI-PAT-2601
```
기본 모드(방법 A)는 역할 카드 진입 그대로 — 인증은 옵트인 계층입니다 (D52).

### 방법 B — 정적 서버 (동기화 없음)

```bash
cd mirimiso-webapp
python3 -m http.server 8080 --bind 0.0.0.0
# → http://localhost:8080
```

### 방법 C — 단일 파일

빌드된 `미리미소-웹앱.html` (384KB, 이미지·CSS·JS 전부 인라인)을
브라우저로 열면 네트워크 없이도 완전 동작합니다(목서버 기능 제외·오프라인 모드).
카톡/이메일로 전달해 시연 가능한 형태입니다.

### 재빌드

```bash
cd mirimiso-webapp && python3 build.py
# → /home/user/미리미소-웹앱.html 생성 (소스를 단일 파일로 인라인)
```

## 6. 기술 노트
- 빌드(build.py)는 terser JS minify + CSS 경량화를 적용해 단일 파일을 **275,668B**로 유지합니다 — 번들 예산은 76차 사용자 승인으로 256KiB→268KiB(274,432B) 상향, S108에서 275,776B로 추가 상향 승인(현 헤드룸 108B). 데모 사진은 WebP(420px) 인라인. 재빌드 전 `npm install`(mirimiso-webapp/) 필요.

- **의존성 제로**: 프레임워크·3D 라이브러리 없이 순수 HTML/CSS/JS. `dental3d.js`에 폴리곤 메쉬 생성, painter's algorithm 정렬 렌더링, 플랫 셰이딩, 화면 공간 피킹을 직접 구현
- **STL 파서**: 바이너리 STL(84바이트 헤더 + 50바이트/트라이앵글) 직접 파싱. 24,000 트라이앵글 상한으로 프레임 보장, ASCII STL은 안내 메시지와 함께 거절
- **캔버스 미지원 환경 가드**: `getContext` 실패 시 렌더러가 안전하게 no-op (테스트·임베드 환경 호환)
- **접근성·규제 가드레일**: 모든 소견 화면에 "비진단 · 교육용/데모" 표기, 시작 전 역할별 동의 모달, 리포트 미동의 환자 배지
