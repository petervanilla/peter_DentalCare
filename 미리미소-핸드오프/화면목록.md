# 미리미소 화면 목록 (Screen Inventory) — S96 기준

> 총 25개 화면. 진입 흐름: 역할 선택 → (역할별 동의) → 역할별 홈. 모든 화면은 상단 앱바(로고·역할 칩·☀/🌙 모드 전환·설정)와 환자 모드 하단 네비 5탭을 공유합니다.

## 공통

| 화면 | 이름 | 설명 |
|---|---|---|
| roleSelect | 역할 선택 (스마일치과) | 메인 진입 — 역할 카드 3종을 아이콘+텍스트 가로 배치. 초대코드 로그인(계정 모드) 포함 |

## 환자 모드 (하단 네비: 홈·오늘의 관리·오늘의 루틴·관리 여정·내 프로필)

| 화면 | 이름 | 핵심 요소 |
|---|---|---|
| home | 환자 홈 | 인사 히어로, 최근 구강 스캔 요약(플라크 지수·날짜·메쉬 익스포트 잔여), 빠른 메뉴 5종(드래그 순서 변경), 다음 방문 D-day |
| sim | 미소 시뮬레이션 | 사진 업로드·관심사 선택 |
| simResult | 시뮬레이션 결과 | 전후 비교·참고 소견 |
| scanIntro | 구강 스캔 (Pro) | Pro 게이트·스캔 소개 |
| captureGuide | 캡처 가이드 | 촬영 템플릿 4종 안내 |
| scanRun | 스캔 진행 | 실시간 스캔 팝업(96포인트·치아 아치 점등) |
| scanResult | 스캔 결과 | 3D 뷰어·FDI 차트·소견 |
| records | 스캔 기록 | 과거 스캔 목록·추이 |
| report | 상담 리포트 | 리포트 요약·인쇄/공유 |
| care | 치료 후 관리 | 회복 체크리스트·상태 사진 추가·기록 |
| today | 오늘의 관리 | 오늘의 기록(통증·부음·출혈 등)·메모·촬영 연계 |
| routine | 오늘의 루틴 | 데일리 루틴 체크 |
| journey | 관리 여정 | 30일 여정·월간 캘린더·완주 리포트 |
| profile | 내 프로필 | 프로필·병원 방문 알람·병원 기록 |
| clinics | 제휴 병원 | 병원 목록 |
| scannerInfo | 스캐너 학습 가이드 | 지원 포맷(STL·OBJ·PLY)·워크플로 안내 |

## 디자인 작업 시 참고

- **모바일 우선**: 본문 폭 560px, 의료진·기공·운영 화면만 1140px 와이드
- **반응형 기준**: 760px 이하 모바일 (모드 전환 버튼은 아이콘만 표시), 진료 Order 3컬럼은 1020px 이하 1컬럼
- **필수 유지 문구**: 각 화면의 "진단이 아닙니다" 비진단 고지, 데모 데이터 고지 — 삭제 금지
- **상태 표현**: 로딩(처리 중 링), 빈 상태, 오류 토스트, 모달 확인 흐름이 화면마다 존재
