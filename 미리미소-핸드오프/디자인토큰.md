## 6. 타이포그래피

- 폰트 스택: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans KR", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`
- 기본 본문 14px / 카드 제목 15px / 화면 대제목 23px(역할 선택)·19.5px(홈 히어로)
- 설명 문구 12.5px · 각주 10.5px · 뱃지 9.5px
- 제목 letter-spacing: -0.3 ~ -0.5px

## 8. 주요 컴포넌트

- **버튼**: primary(포인트 배경·풀폭) / ghost(흰 배경+테두리) / soft(연배경) / steel(의료진 톤) / dark(진회색) / small 변형
- **뱃지**: ok·warn·info·gray·pro(골드)
- **카드**: 기본 카드(제목+설명), 히어로 카드, 통계 칩, 빠른 메뉴 카드(아이콘 34px 박스)
- **FDI 치아 차트**: 상악 16 + 하악 16 셀 — 상태별 색 (임플란트=포인트, 크라운=블루, 관찰=주의, 결손=점선)
- **하단 네비** (환자 모드): 홈·오늘의 관리·오늘의 루틴·관리 여정·내 프로필 5탭
- **모달**: 하단 grab 핸들 + 제목 + 내용 + 버튼 스택
